# ProteinMPNN Demo Data

## mini_helix.pdb

Minimal 5-residue alanine alpha-helix backbone structure for quick testing.

- **Chain**: A
- **Residues**: 5 (ALA 1-5)
- **Atoms**: 20 (N, CA, C, O per residue)
- **Expected native sequence**: AAAAA
- **Typical inference time**: < 1 second

This PDB provides backbone coordinates (N, CA, C, O) which is the minimum
input required by ProteinMPNN for inverse folding / sequence design.
